🎵 Mood Weather: Gökyüzünün Ritmini Yakala! ☁️
Mood Weather, sadece hava durumunu söylemekle kalmayan, o anki atmosfere ve ruh haline en uygun müziği senin için seçen akıllı bir web uygulamasıdır.

(Not: Buraya kendi ekran görüntünü veya yukarıdaki görsellerden birini ekleyebilirsin)

✨ Öne Çıkan Özellikler
🌡️ Akıllı Mod Algoritması: Sadece hava durumuna (güneşli, yağmurlu vb.) değil; sıcaklığa ve günün vaktine (gece/gündüz) göre şarkı listelerini değiştirir.

Örn: Hava 10°C altındaysa "Soğuk Gün Acoustic", gece ise "Late Night Vibes" listeleri gelir.

📍 Tek Tıkla Konum: Geolocation API kullanarak saniyeler içinde bulunduğun yerin verisini çeker.

🎨 Dinamik Tema: Hava durumuna göre tüm arka plan renkleri ve cam (glassmorphism) efektleri anlık olarak değişir.

🎶 Entegre Spotify Player: Sayfadan ayrılmadan, o anki moduna uygun çalma listesini direkt uygulama üzerinden dinleyebilirsin.

🛠️ Kullanılan Teknolojiler
Frontend: HTML5, CSS3 (Advanced Flexbox & Grid, CSS Variables)

JavaScript: ES6+ (Fetch API, Geolocation API, Async/Await)

Dış Servisler: * OpenWeatherMap API (Hava durumu verileri)

Spotify Embed API (Müzik çalma listeleri)

tsParticles (Arka plan animasyonları)

🚀 Nasıl Çalıştırılır?
1.Bu projeyi bilgisayarınıza klonlayın:

git clone https://github.com/kullaniciadi/mood-weather.git


2.script.js dosyasını açın ve apiKey değişkenine kendi OpenWeatherMap API anahtarınızı ekleyin:

const apiKey = 'SİZİN_API_ANAHTARINIZ';
index.html dosyasını tarayıcınızda açın ve müziğin tadını çıkarın!
